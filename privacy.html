CookieSmith Privacy Policy

Last Updated: October 5, 2026
Zero Telemetry • 100% Local • Open Source
CookieSmith collects zero user data, logs zero analytics, and makes zero network requests. All cookie inspections, additions, edits, deletions, imports, and exports occur entirely on your local machine.

1. Data Collection: None

CookieSmith does not collect, record, or transmit:

  • Cookie names, values, or attributes
  • Browsing history or URLs visited
  • IP addresses or device identifiers
  • Usage analytics or crash telemetry
  • Personal or sensitive user information

2. Permissions Justification

CookieSmith requests the minimum permissions required by Chrome to fulfill user actions:

Permission Type Exact Purpose
cookies API Allows reading, adding, modifying, and deleting cookies when you open the popup. Data never leaves your machine.
activeTab API Allows reading the active tab's domain to filter cookies specific to the site you are currently visiting.
storage API Allows storing non-sensitive local UI preferences (like sort order) within your browser's local storage.
<all_urls> Host Required by Chrome for the chrome.cookies API to inspect cookies on whichever site you choose to open the tool on.

3. Third-Party Services

CookieSmith connects to zero external services. It contains no tracking SDKs, no advertising code, and no external font/asset CDNs.

4. Independent Verification & Auditing

CookieSmith is 100% open source. You can inspect the source code, verify that no outbound network requests occur in Chrome DevTools Network panel, and build the extension directly from source.

5. Contact

For questions or verification inquiries, please visit our open source repository at github.com/CKosick/cookiesmith or contact cliff@cookiesmith.dev.
